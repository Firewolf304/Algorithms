# Practice 4

D. Быстрый поиск в массиве
ограничение по времени на тест
2 секунды
ограничение по памяти на тест
512 мегабайт

Дан массив a
из n целых чисел a1,a2,…,an

.

Нужно уметь отвечать на запросы вида «Сколько чисел имеют значения от l до r»?
Входные данные

В первой строке находится целое число n
(1≤n≤10^5) — длина массива.

Во второй строке находятся n
целых чисел a1,a2,…,an (−10^9 ≤ a_i ≤ 10^9).

В третьей строке находится целое число k
(1≤k≤10^5) — число запросов.

В следующих k
строках находятся пары чисел l r (−10^9≤l≤r≤10^9).
Выходные данные

Выведите k

чисел — ответы на запросы.

Скопировать

5
10 1 10 3 4
4

2 9
